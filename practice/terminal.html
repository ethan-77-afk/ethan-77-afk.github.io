what is vim?

Vim is the keyboard based text editor for files

how to open vim

  1. First,open launchpad and navigate to terminal.
  2. Then, navigate to the file you want to open using cd
  4. Finally, type vim and then the file name

    5. How to close vim

    Closing vim seems difficult at first, however it is not nearly as challenging as it seems

    1. First, simply click escape to get out of whatever mode you were in before
    2. Next, type the : key
    3. Finally, type wq

    Some useful vim commands

      		
    • 	Use :wq to exit vim and save.
		
    • 	Use :q to quit vim without saving.
		
    •     If the computer responds with an error like E37: No write since last change    Use :q! to quit while bypassing potential error message
